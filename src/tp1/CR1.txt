Les boutons les plus importants du Debugger :

 Resume Program : Continue l’exécution jusqu’au prochain breakpoint ;
 Stop Program : Stoppe l’exécution du programme ;
 Step Over : Exécute la ligne courante sans entrer dans la méthode (ou constructeur) appelé(e) ;
 Step Into : Rentre dans le code de la méthode (ou constructeur) appelé(e) sur la ligne courante ;
 Step Out : Sort de la méthode (ou du constructeur) appelé(e).
